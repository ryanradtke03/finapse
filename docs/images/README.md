# Screenshots

Drop the app screenshots here. The root `README.md` references these exact
filenames, so match them:

| File               | View                                                        |
| ------------------ | ----------------------------------------------------------- |
| `dashboard.png`    | Dashboard — spending/income/net totals, category breakdown, spending-over-time chart |
| `transactions.png` | Transactions list — filters (date/category/search) and a row selected |
| `budgets.png`      | Budgets — per-category monthly limits with spent-vs-limit progress |

Tips:

- Use the demo data (`SEED_DEMO`) so the views look full and no real bank data
  is shown.
- Capture at a normal browser width (~1280–1440px) and crop out browser chrome.
- PNG keeps text crisp. Aim for a reasonable file size (< ~500 KB each).
